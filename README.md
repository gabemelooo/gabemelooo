## Sobre mim

Estudante de Sistemas de Informação, com forte interesse em tecnologia e desenvolvimento de software. Iniciei minha jornada na programação aos 14 anos com desenvolvimento de jogos, adquirindo uma base sólida em lógica de programação e resolução de problemas. Aos 16, aprofundei meus conhecimentos em HTML, CSS (Bootstrap) e JavaScript, desenvolvendo projetos práticos voltados a aplicações reais. Atualmente, direciono meus estudos para o desenvolvimento back-end, com foco em Java/Springboot, APIs, banco de dados e arquitetura de sistemas, mantendo um perfil autodidata, com aprendizado contínuo e foco em boas práticas, performance e escalabilidade.
